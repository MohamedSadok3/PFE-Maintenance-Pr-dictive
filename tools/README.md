# Outils de préparation des données

Le dossier `kaggle/` contient les utilitaires utilisés pour télécharger et préparer les datasets destinés à la future reconstruction ML.

Ces outils ne sont pas nécessaires au fonctionnement de SmartMaintain avec Docker. Consultez [`kaggle/README.md`](kaggle/README.md) pour leur configuration et leur utilisation.

Les identifiants Kaggle (`kaggle.json`, tokens et dossier `.kaggle`) ne doivent jamais être ajoutés à Git.
